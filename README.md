# Heloisa Sampaio - Site Institucional

Projeto de landing page institucional para a psicóloga Heloisa Sampaio, desenvolvido com HTML5, CSS3 e JavaScript puro.

## Estrutura

- `index.html` — página principal
- `css/style.css` — estilos gerais
- `css/responsive.css` — ajustes responsivos
- `js/script.js` — menu mobile, FAQ e lightbox
- `assets/images/` — imagens e placeholders organizados por categoria
- `pages/politica-privacidade.html` — política de privacidade
- `pages/termos.html` — termos de uso
